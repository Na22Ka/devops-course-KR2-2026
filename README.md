## Практическая работа №5

- [Скрипт аудита](scripts/audit.sh)

Скрипт запускается на Ubuntu: `bash scripts/audit.sh`. Для проверки конфигурации
нужны права sudo. Код 0 означает успешное прохождение проверок, код 1 — ошибку.

Образы ОС, виртуальные диски, SSH-ключи и пароли в репозитории не хранятся.
